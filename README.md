## Про проєкт
"HoDis" - це прототип інтелектуальної освітньої платформи, призначеної для організації навчального процесу, управління курсами та автоматизованого тестування знань студентів. Особливістю платформи є інтеграція інтелектуальних методів обробки даних (LLM) для надання персоналізованих пояснень помилок.

## Структура проєкту
* `main.py` — точка входу системи.
* `README.md` — опис проєкту.
* `.gitignore` — файл виключень для системи контролю версій.

## Технології
* **Мова програмування:** Python
* **Контроль версій:** Git / GitHub
